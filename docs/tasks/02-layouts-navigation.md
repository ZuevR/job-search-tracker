## Условие

**Зачем:** почти каждое приложение — это «публичная часть + кабинет с боковым меню». Здесь отрабатываются вложенные layouts (и то, что они не перерисовываются при навигации), клиентские переходы через `Link` вместо полной перезагрузки, а также `<title>`/SEO через Metadata API и шрифты без layout shift. Вопросы «как работает навигация в App Router» и «как задать title для каждой страницы» встречаются часто.

**Прочитать:**
- https://nextjs.org/docs/app/getting-started/layouts-and-pages — разделы про nested routes, nested layouts и linking between pages.
- https://nextjs.org/docs/app/getting-started/linking-and-navigating — до раздела «What can make transitions slow?».
- https://nextjs.org/docs/app/getting-started/metadata-and-og-images — static metadata; плюс `title.template`: https://nextjs.org/docs/app/api-reference/functions/generate-metadata#template
- https://nextjs.org/docs/app/getting-started/fonts — бегло.

**Сделать:**
1. Маршруты (страницы — заглушки с заголовком `h1` и строкой текста):
   - `/` — лендинг
   - `/login` — вход
   - `/dashboard` — «Обзор»
   - `/dashboard/vacancies` — «Вакансии»
   - `/dashboard/applications` — «Отклики»
2. Корневой layout: шапка с названием проекта и ссылками «Главная», «Кабинет», «Войти».
3. Layout кабинета (`/dashboard/*`): боковое меню со ссылками на три страницы кабинета. В это же меню добавь обычный `<input placeholder="Быстрый поиск">` без всякого state — он нужен для эксперимента.
4. Все переходы — через `next/link`.
5. Metadata:
   - в корне `title` с `template` (например, `«%s | Job Tracker»`) и `default`, плюс осмысленный `description`;
   - каждая страница задаёт свой `title`;
   - `<html lang>` — под язык контента.
6. Шрифт: кириллица должна рендериться выбранным шрифтом, а не системным fallback. Сейчас это не так — разберись почему.
7. Стили минимальные (Tailwind-классы из коробки или вообще без стилей). Дизайн будет в задаче 3.
8. Удали неиспользуемый `Image` и прочий мусор от шаблона. `yarn lint` — без предупреждений. Закоммить (вместе с `docs/` и `CLAUDE.md`) и запушь.

**Вопросы к ревью:**
1. Шапка использует клиентский хук `usePathname`, но все маршруты `○`. Почему клиентский код не сделал их динамическими?
2. На `/` стоит `absolute`, на остальных страницах — свой `title`. Где тогда вообще покажется `default: 'Job Tracker'`?
3. Что `next/font` делает с Google-шрифтом при сборке, и что такое `"Geist Fallback"` в computed `font-family` у `<html>`?

**Ответы Ромы (16.11):**
1. «Клиентский ≠ динамический; на сервере генерируется, дальше JS на фронте; динамические — это `ƒ`» — 🟡. «Где» сказано верно, «что делает динамическим» — нет. Нужно было назвать данные запроса: `cookies()`, `headers()`, `searchParams`, `connection()`, некэшированные данные. `usePathname` на статичность не влияет, потому что путь каждого маршрута известен уже при сборке. Эталон есть в `interview-bank.md` (§1, вопрос про `○`), это повтор из задачи 1.
2. «Там, где не передадим title» — ✅. Пример в проекте — `/_not-found`.
3. «Оптимизирует и хостит; fallback — оптимизация Next; шрифт из `className`» — 🟡. Не хватило: файлы скачиваются **при сборке** и раздаются с нашего домена, браузер в Google не ходит. `Geist Fallback` — это локальный Arial, подогнанный под метрики Geist (`adjustFontFallback`), чтобы при подмене шрифта не было layout shift (CLS). `geistSans.variable` шрифт **не применяет**, он только объявляет CSS-переменную `--font-geist-sans` на `<html>`. Применяет тот, кто её использует, и это ключ к 🔴 со шрифтом.

## Вопросы на понимание

**Почему текст в «Быстром поиске» сохраняется?**
- Внутри кабинета. Ответ Ромы: «клиентский компонент, перерендеривается только нажатая кнопка» — 🔴 неверно. Правильно: инпут лежит в `dashboard/layout.tsx`, а это общий layout для `/dashboard/*`. При навигации меняется только сегмент `page` (`children`), layout не перемонтируется, и DOM-узел инпута остаётся тем же. Layout при этом серверный компонент: React-state у инпута нет, сохраняется именно DOM-state.
- `/` и обратно. Ответ Ромы: `cacheComponents` → `<Activity>`, кабинет прячется через `display: none` — ✅. Дополнение: Next хранит до 3 маршрутов, самый старый вытесняется.

**Когда сохранение состояния вредит и как его сбросить?** Ответ Ромы про сброс: «ключ от специальной функции» — 🟡 частично. Разбор — в ответе ментора от 15.11; эталон — в `interview-bank.md` после задачи.

**Что такое RSC payload и почему там не HTML?** Объяснено 15.11, закрепляется в задаче 3.
